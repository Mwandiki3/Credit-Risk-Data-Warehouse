1. Architectural Overview & Metadata

PropertySpecification
Database Objectgold.vw_customer_credit_profile
Object TypeVirtual Database View (Denormalized Analytical Base Table / Customer 360 Feature Store)
Data GrainOne unique row per loan applicant (customer_id), totaling 307,511 distinct records
Primary PurposeConsolidates core demographics, declared income, external bureau debt, revolving credit card usage, POS/cash loan balances, and historical installment discipline into a single flat feature matrix
Null Handling PolicyAll aggregated historical metrics use ISNULL(..., 0) so thin-file borrowers default cleanly to 0 rather than NULL
